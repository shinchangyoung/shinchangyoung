이 코드는 Node.js의 기본 모듈인 http, fs, url을 활용하여 간단한 웹 서버를
 구현한 것이다. 사용자가 브라우저를 통해 접속할 때 URL의 쿼리스트링에 포함된 
 id 값을 읽어와, 해당 값을 페이지의 제목(title)과 본문에 동적으로 반영한다.

예를 들어, http://localhost:3000/?id=HTML로 접속하면, 페이지 제목과 
본문 제목이 HTML로 나타난다. 이는 하나의 HTML 템플릿을 기반으로 다양한 
내용을 표현할 수 있도록 구성한 방식이다. 따라서 HTML 파일을 여러 개 따로 만들지 
않고도 하나의 코드로 여러 페이지를 표현할 수 있다.

기본 주소(http://localhost:3000/)로 접속하면 id 값이 없으므로 기본값 
'toyoaki'를 title로 설정하여 보여준다. 또한 브라우저가 자동으로 요청하는
 /favicon.ico는 404 응답으로 처리해 불필요한 리소스를 차단하고 있다.

이러한 구조는 template 문자열 안에 ${title}을 삽입하여 제목을 동적으로 
변경하고, <ul> 태그의 항목들을 통해 서로 다른 id 값으로 이동할 수 있는 링크를 
제공한다. 이렇게 함으로써 하나의 템플릿만 수정하면 모든 페이지에 공통적으로 
적용되므로 유지보수가 쉬워지고, 콘텐츠 변경도 효율적으로 이루어진다.
